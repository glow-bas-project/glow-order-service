# GLOW Order Service

Backend microservice responsible for handling order-related functionality within the GLOW platform. It is independently deployable and forms part of the larger GLOW microservices architecture.

The service is built with **Java 25** and **Quarkus**, using **PostgreSQL** for persistence and **Liquibase** for database migrations. It exposes REST APIs and uses **OpenID Connect (OIDC)** for authentication and authorization, with support for Kubernetes-based deployment.

Technologies:
* Java 25 & Quarkus
* PostgreSQL & Liquibase
* REST API
* OpenID Connect (OIDC)
* Kubernetes
* Gradle
